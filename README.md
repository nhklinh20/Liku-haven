# Liku Haven

Liku Haven, chốn bình yên của Linh: căn phòng tương tác với kệ sách (PDF, EPUB, manga), rạp phim, kho file, góc cặp đôi, trò chơi, thông báo và điểm thưởng.

- Chạy trên trình duyệt điện thoại, máy tính bảng và máy tính.
- Cài lên màn hình chính: mở trang bằng Chrome (Android) hoặc Safari (iPhone/iPad), chọn "Thêm vào màn hình chính".
- Dữ liệu hiện lưu trên từng máy. Đăng nhập và đồng bộ sẽ dùng Firebase (dự án Liku).
